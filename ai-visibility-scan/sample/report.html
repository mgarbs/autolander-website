What to fix first

Top 3 fixes

1

Let AI search crawlers read your vehicle pages

robots.txt keeps PerplexityBot out of the vehicle pages checked. Allow the inventory paths so engines can read the cars you actually have in stock.

2

Put price, mileage and VIN in the vehicle-page HTML

3 of 5 vehicle pages checked do not show the price or VIN as plain text. Many crawlers read the raw HTML without running scripts, so values filled in by JavaScript can be invisible to them. Add them to the page HTML and to Vehicle structured data.

3

Complete your Cars.com, CarGurus, Autotrader profiles

Engines cited Cars.com, CarGurus, Autotrader 89 times in this scan, but never a page of yours there. Claim and complete those profiles with the same name, address, phone and hours as your website.

Method

SAMPLE — mock data. No engine was queried for this report: every answer is a fixture generated offline to show the format. In a live scan, answers are collected through each engine's official API on the scan date, 3 runs per question, location set to Raleigh, NC. Answers vary run to run. AutoLander is not affiliated with OpenAI, Perplexity or Anthropic.

Engines: OpenAI API (mock); Perplexity API (mock); Anthropic API (mock). A dealer counts as named when the answer text contains its name, a close variant of it, or its website address. The score weighs Presence 50 · Sources 15 · Reputation 20 · Technical 15 points; a part that could not be assessed is left out and the total is renormalised to 100.

This report describes what the engines answered on the scan date. It does not predict rankings, traffic or sales.
